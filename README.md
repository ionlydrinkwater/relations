# Relations

Relations is a website-first personal tool for keeping track of family and
friends. It is intended to make it easier to remember useful details about the
people in your life and important dates such as birthdays.

## Stack

- SvelteKit with TypeScript
- PostgreSQL for data, accessed from server code
- Google sign-in with Auth.js
- Docker containers to run everything locally
- Responsive layouts so the website is comfortable to use on phones

The app is at an early stage and has not been scaffolded yet. Data lives in a
local Docker volume, so it is not backed up automatically.
See [PROJECT_PLAN.md](./PROJECT_PLAN.md) for scope and next steps.
